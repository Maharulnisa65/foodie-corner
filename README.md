# Foodie Corner Website

A responsive food/recipe website made with plain HTML, CSS, and JavaScript. No installation or build step is needed.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in your web browser.

## Publish using GitHub Pages
1. Sign in to https://github.com/ or create an account.
2. Click the **+** icon, then **New repository**.
3. Name the repository `foodie-corner` and choose **Public**.
4. Click **Create repository**.
5. Click **Add file** → **Upload files**.
6. Upload `index.html` (and this `README.md` if you like). If you extracted the ZIP, upload the files inside the folder, not the ZIP itself.
7. Click **Commit changes**.
8. Open the repository's **Settings** → **Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Choose branch **main** and folder **/(root)**, then click **Save**.
11. Wait a minute or two. Your website link will appear on the Pages settings screen, usually like:
   `https://YOUR-USERNAME.github.io/foodie-corner/`

## Customize it
- Open `index.html` in a text editor to change the title, recipes, colours, and text.
- The newsletter form is only a demo; it does not send or store emails.
- This site uses emoji illustrations, so it does not require image downloads.
