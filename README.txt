FOODIE CORNER - SEO WEBSITE

Is folder ki sari files GitHub repository (foodie-corner) ke ROOT main upload karein,
aur purani index.html ko replace kar dein. Folder ka structure same rehna chahiye:

  index.html, about.html, contact.html, privacy-policy.html, 404.html
  style.css, favicon.svg, robots.txt, sitemap.xml
  recipes/  (6 recipe pages)

Upload ke baad:
1. Settings -> Pages main branch main aur folder /(root) select hona chahiye.
2. Google Search Console (search.google.com/search-console) main
   https://maharulnisa65.github.io/foodie-corner/ add karein.
3. Sitemap section main  sitemap.xml  submit karein.
4. Nayi recipe add karne ke liye recipes/ main kisi file ki copy banayein,
   text badlein, aur sitemap.xml main nayi line add karein.
